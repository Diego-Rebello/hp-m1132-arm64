# hp-m1132-arm64

A **native arm64** CUPS driver for the **HP LaserJet Professional M1132 MFP** on macOS 27 (Apple Silicon). No Rosetta, no Ghostscript, and none of HP's Intel drivers.

## The problem

HP's macOS drivers for the M1130/M1210 series (and the other ZjStream LaserJets) ship Intel-only CUPS filters (`x86_64 i386`). macOS 27's CUPS refuses to launch them: the job fails with `com.apple.badarch-error` and `Broken pipe`, and 0 bytes reach the printer. This happens even with Rosetta installed, because the block is in CUPS itself. HP has not released an arm64 version.

## How it works

- `rastertozjs` is a CUPS filter (raster → ZjStream) from [faradayfury/printer-all](https://github.com/faradayfury/printer-all), a rewrite of [foo2zjs](http://foo2zjs.rkkda.com/). It builds natively for arm64.
- **Model 4 (`MODEL_HP_M1132`)** was added to it. It produces the same stream structure as HP's own Mac filter. The M1132 stalls the USB pipe on the P1102 stream (`foo2zjs -z2`), so the existing models do not work. The details are in [`docs/parameters.md`](docs/parameters.md) §5.
- The PPD is this project's own, generated by `scripts/make_ppd.py`. It offers 13 paper sizes, paper type, density (1–5), EconoMode and collated copies, with 600×600 dpi monochrome output.
- Everything is installed under `/Library/Printers/`, which System Integrity Protection does not block. Nothing goes into `/usr/libexec/cups`.

## Status

Tested on an **HP LaserJet Professional M1132 MFP** over USB, on **macOS 27.0.1 (26A434), Apple Silicon**, in October 2026:

- ✅ ruler test page (A4, 1 and 2 pages), Word, Preview and Safari
- ✅ print dialog options: paper size, paper type, density, EconoMode, copies with and without collation
- ⚠️ the other paper sizes were only checked offline (correct `DMPAPER` in the stream)
- ❌ the scanner is not covered

Other ZjStream printers (P1102, M1212nf, …) are **not** tested. The PPD is specific to the M1132.

## Install

Requirements: the Xcode Command Line Tools (`xcode-select --install`), Python 3, and the printer connected over USB.

```sh
git clone https://github.com/Diego-Rebello/hp-m1132-arm64.git
cd hp-m1132-arm64
make check                    # builds rastertozjs and zjsdecode and checks they are arm64
sudo ./scripts/install.sh     # in Terminal.app; prompts for your password
```

`install.sh`:
- copies the filter to `/Library/Printers/hp-m1132-arm64/rastertozjs` (`root:wheel 755`, ad hoc signature);
- copies the PPD to `/Library/Printers/PPDs/Contents/Resources/` and validates it with `cupstestppd`;
- creates a **new** queue, `M1132_arm64` ("HP M1132 (arm64)"), unshared. Existing queues are left alone.

It finds the USB URI on its own (with `lpinfo`, or from an existing HP M1132 queue). To set it yourself: `sudo URI='usb://…' ./scripts/install.sh`.

Optional:
```sh
lpoptions -d M1132_arm64                                   # make it the default printer
defaults write org.cups.PrintingPrefs UseLastPrinter -bool false   # keep macOS from switching back to the "last used" printer
```

## Uninstall

```sh
sudo ./scripts/uninstall.sh
```

This removes the `M1132_arm64` queue, the filter and the PPD.

## Testing without the printer

```sh
mkdir -p out
python3 scripts/make_testpage.py test     # test/ruler-a4.pdf and test/ruler-letter.pdf
cupsfilter -p ppd/HP-LaserJet_Professional_M1132_MFP-arm64.ppd \
  -m application/vnd.cups-raster test/ruler-a4.pdf > out/test.ras
./rastertozjs 1 u t 1 "" out/test.ras > out/test.zjs
python3 -I tools/zjsdump.py out/test.zjs  # lists the stream's chunks and items
```

See [`docs/parameters.md`](docs/parameters.md) for the protocol analysis and the offline test results, and [`PLAN.md`](PLAN.md) for the project log.
