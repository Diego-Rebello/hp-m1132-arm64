Third-party files were copied unmodified, with one exception:

- **`src/rastertozjs.c` (Phase 3, 2026-10-12):** the default Model now comes from the `DEFAULT_MODEL` macro, which the `Makefile` set to `2` (`MODEL_HP_PRO`, equivalent to `foo2zjs -z2`). Without the macro the default stayed `MODEL_HP1020`, as in the original. Reason: CUPS does not pass PPD defaults to the filter in `argv[5]`, so a `*DefaultModel` in the PPD would never arrive. 7 lines, marked `hp-m1132-arm64` in the comment.
- **`src/rastertozjs.c` (Phase 3 review, 2026-10-12):** the filter reads the queue's PPD (`$PPD`): the Model from `*cupsModelNumber` and the `Density`/`EconoMode`/`Collate` defaults. The default without a PPD became `MODEL_HP_PRO` in the code itself (the `-D` was removed from the Makefile). `EconoMode` accepts `True`/`On`. The paper type uses `cupsMediaType` when the PPD sets it, and the `Heavy` name changed from 261 to 262 (HP's code), with `MidWeight` 282 and `ExtraHeavy` 283. Copies: reads `argv[4]` when `NumCopies` is 1 and, with `Collate`, repeats the document instead of asking the printer for copies. Changes marked `hp-m1132-arm64`.
- **`src/rastertozjs.c` (Phase 5, 2026-10-12):** new **Model 4 (`MODEL_HP_M1132`)**, now the default, with the stream HP's own Mac filter sends to the M1132: PJL with CRLF and `ENTER LANGUAGE=ZJS`, `START_DOC` with `DMCOLLATE` only, page items in ID order with `ECONOMODE` and no `RET`/`START_PLANE`. The job title goes into `@PJL JOB NAME` (printable ASCII only, no quotes, up to 63 characters). Models 0–3 are unchanged: Model 2 output is byte-for-byte identical. Reason: the M1132 stalls the USB pipe on the Model 2 stream (see `docs/parameters.md` §5).

Other changes are recorded in the git history.

In Phase 1 the base was `rastertoxqx.c` (XQX). It was replaced in Phase 2, once it was confirmed that the M1132 uses ZjStream (see `docs/parameters.md`).
